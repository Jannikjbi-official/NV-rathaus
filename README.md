# Rathaus Nordverkehr

Bürgerportal der Stadtverwaltung im Roleplay-Projekt [Nordverkehr](https://nordverkehr.xyz).

- Next.js 16 · HeroUI v3 · Gravity Icons · Tailwind CSS v4
- Datenbank: Neon Postgres (`.env`, siehe `.env.example`)
- Hosting: Vercel

Status: Design-Phase. Die aktuelle Vorschau der Startseite liegt unter `docs/preview/startseite.html`.

```bash
pnpm install
pnpm dev
```
